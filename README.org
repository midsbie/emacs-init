#+TITLE: emacs-init
#+AUTHOR: Miguel Guedes
#+DATE: 03/05/2014

Personal Emacs configuration.

* Usage

Load =src/init.el= from =~/.emacs=:

#+begin_src emacs-lisp
(load "/path/to/emacs-init/src/init.el")
#+end_src

=src/debug-init.el= sets up packages and =use-package= only, without loading the config, for debugging: =emacs -Q -l src/debug-init.el=.

* Layout

Directories under =src/= load in the order below. Within each directory, files load alphabetically.

| Directory         | Contents                                     |
|-------------------+----------------------------------------------|
| =config/=         | Built-in settings, keybindings, constants    |
| =features/=       | External packages, one per file              |
| =extra-features/= | Utility commands as plain =defun= forms      |
| =modes/=          | Major-mode setup, one per file               |
| =environment/=    | =x.el= (GUI) or =term.el= (terminal), themes |
