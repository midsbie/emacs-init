#+TITLE: emacs-init
#+AUTHOR: Miguel Guedes
#+DATE: 03/05/2014

Personal Emacs configuration.

Requires Emacs 31.1 or later for native User Lisp startup support (=prepare-user-lisp=).

* Usage

Link the repository into =~/.emacs.d= and point Emacs's entry points at =src/=. A =~/.emacs= file would take precedence over =init.el=, so there must not be one:

#+begin_src sh
ln -s /path/to/emacs-init ~/.emacs.d/init
cd ~/.emacs.d
ln -s init/src/early-init.el early-init.el
ln -s init/src/init.el init.el
ln -s init/src/user-lisp user-lisp
#+end_src

Identity, mail and per-host settings go in =~/.emacs.d/personal.el=, which loads if present, and customizations are saved to =~/.emacs.d/custom.el=, both outside the repository.

On first launch, missing packages install into =elpa/= from GNU ELPA, NonGNU ELPA and MELPA, or from their git repositories for packages declared with =:vc=.

=src/debug-init.el= applies =early-init.el= and activates packages only, without loading the config, for debugging: =emacs -Q -l src/debug-init.el=.

* Layout

=src/early-init.el= holds settings that precede package activation or initial frame creation. =src/init.el= bootstraps module and theme paths, sets the package installation policy, requires modules in order, then loads =personal.el= and =custom.el=. Configuration modules own settings and activation; =user-lisp/= libraries provide functionality without activating it on load.

Environment setup also runs when client frames are created, so a graphical client of an Emacs daemon loads the GUI configuration; the daemon's initial frame loads none. Each environment module loads once and its themes apply to the whole Emacs process, so graphical and terminal frames in one process share faces.

| Directory      | Contents                                                    |
|----------------+-------------------------------------------------------------|
| =config/=      | Core settings, keybindings and user-library configuration  |
| =features/=    | Package configuration, one library per file                 |
| =modes/=       | Major-mode setup, one per file                              |
| =environment/= | Frame dispatch and GUI/terminal configuration              |
| =user-lisp/=   | Utility commands, compiled by Emacs and loaded on first use |
| =themes/=      | Custom themes                                               |

Each =use-package= declaration lives in =init-LIBRARY.el= under =features/= or =modes/=. Companion libraries have separate modules. =config/= and =environment/= contain ordinary Emacs Lisp setup. The explicit =require= list in =src/init.el= loads core settings first, then package and mode modules; dependency declarations precede modules whose setup loads them.
